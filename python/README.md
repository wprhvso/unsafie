# unsafie — backend

Смотри README в корне репозитория.

```
uv sync
cp .env.example .env
python -m unsafie
```

## Вывод агента

Агент генерирует блоки кода на Nushell: ````nu ... ````. Код исполняется напрямую на локальной машине через вызов интерпретатора Nushell с пробросом переменных окружения текущего хода. Для взаимодействия с сервисами агенту предоставлена специализированная CLI-утилита `unsafie`, возвращающая все данные в JSON.
